# Security Policy

## Supported Versions

This security policy is universal to all main branch releases to the HARBOR repository.

## Reporting a vulnerability

If you find a security bug, please do not open a public issue. Instead, send an email to `krcdev01@gmail.com`. 

Please include:
* A description of the bug.
* How to trigger it.
* Any proof-of-concept code or steps to reproduce.

I will reply within **7 days** to confirm I received your report and respond with findings. I will then work with you to fix the problem.
